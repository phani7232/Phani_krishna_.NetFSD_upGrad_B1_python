# Smart IT Service Desk & System Monitoring Automation

## Overview
A complete Python-based backend automation project for TechNova Solutions. This system replaces manual helpdesk support by automating ticket creation, incident management, SLA tracking, and system monitoring alerts.

## Project Architecture & Python Concepts Used
This project strictly follows Advanced Python and OOP principles:
- **Core Python**: File IO, Exception Handling, Loops, Dictionaries.
- **Advanced Python**: Generators (for searching tickets), Map/Filter/Reduce (in reporting module), Decorators (for action logging), and Regex (input validation).
- **OOP Concepts**: Inheritance, Polymorphism, Encapsulation, Special Methods, and Static Methods.
- **ITIL Workflows**: Automated Incident, Service Request, Problem, and Change Management routing.
